# Quick Start

1. Make some changes to files in the 'Public/' directory of my obsidian vault
2. Ensure changes are to files with the tag 'publish: true'
3. Run `npx quartz sync` from the root dir of this repo to publish

# Quartz v4

Quartz is a set of tools that helps you publish your [digital garden](https://jzhao.xyz/posts/networked-thought) and notes as a website for free.
